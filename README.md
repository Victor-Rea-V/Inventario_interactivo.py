# Sistema de Inventario de Fincas de Cacao 

Proyecto en Python desarrollado para gestionar fincas agrícolas, evolucionando desde datos estáticos hasta una aplicación interactiva.

## ¿Qué hace esta versión?
* Almacena registros de fincas agrícolas usando **listas y diccionarios**.
* **¡Nuevo!** Permite registrar **nuevas fincas en tiempo real** mediante la consola usando la función `input()`.
* Utiliza métodos dinámicos como **`.append()`** para agregar los nuevos datos a la memoria del programa.
* Implementa ciclos (`for`), funciones (`def`) y condicionales (`if`) para filtrar fincas por hectáreas.

## Tecnologías utilizadas
* Python 
* Visual Studio Code
